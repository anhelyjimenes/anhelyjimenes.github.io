Instalación de Ubuntu 20.04.6 LTS

Manual paso a paso en Oracle VM VirtualBox para prácticas de Seguridad Informática.

1. Objetivo

Instalar y configurar Ubuntu 20.04.6 LTS en una máquina virtual utilizando Oracle VM VirtualBox, dejando el sistema preparado para futuras prácticas.

2. Archivo ISO utilizado

ubuntu-20.04.6-desktop-amd64.iso

La imagen ISO fue descargada y posteriormente utilizada como medio de instalación dentro de VirtualBox.

3. Creación de la máquina virtual

Paso 1. Crear una nueva máquina

En Oracle VM VirtualBox se seleccionó la opción Nueva.

Nombre: Ubuntu 20.04.6
Tipo: Linux
Versión: Ubuntu (64-bit)

Paso 2. Asignar memoria RAM

Se asignaron 4096 MB de memoria RAM.

Paso 3. Crear el disco virtual

Se seleccionó la opción Crear un disco duro virtual ahora.

Tipo: VDI (VirtualBox Disk Image)
Almacenamiento: reservado dinámicamente
Tamaño: 30 GB

Paso 4. Configurar el procesador

En Sistema → Procesador se asignaron 2 CPU.

4. Configuración de pantalla

Para mejorar la visualización del instalador se ajustó la configuración gráfica.

Memoria de vídeo: 128 MB
Controlador gráfico: VMSVGA
Monitores: 1

5. Montaje de la imagen ISO

Desde Configuración → Almacenamiento se seleccionó la unidad óptica virtual y se cargó:

ubuntu-20.04.6-desktop-amd64.iso

6. Inicio de la instalación

Se inició la máquina virtual y, en la pantalla inicial de Ubuntu, se seleccionó el idioma Español.

Luego se seleccionó:

Instalar Ubuntu

7. Configuración del teclado

Se seleccionó la distribución:

Spanish (Latin American)

Se verificó el funcionamiento de caracteres especiales antes de continuar.

8. Actualizaciones y software

Se utilizó la configuración:

  • Instalación normal.
  • Descargar actualizaciones al instalar Ubuntu.
  • Instalar programas de terceros.

9. Tipo de instalación

Borrar disco e instalar Ubuntu
Esta opción afectó únicamente al disco virtual de 30 GB creado para Ubuntu, no al disco físico de Windows.

10. Confirmación de particiones

Ubuntu mostró la confirmación para escribir los cambios en el disco virtual. Se revisó la información y se seleccionó Continuar.

11. Zona horaria

Se seleccionó Lima como ubicación y zona horaria.

12. Creación del usuario

Se creó la cuenta de usuario para iniciar sesión en Ubuntu.

  • Nombre de usuario configurado.
  • Nombre del equipo configurado.
  • Contraseña de acceso definida.
  • Se seleccionó solicitar contraseña al iniciar sesión.
Las contraseñas no deben publicarse en GitHub ni mostrarse en documentación pública.

13. Proceso de instalación

Ubuntu realizó la copia de archivos, instalación de paquetes y configuración del sistema operativo.

14. Reinicio

Al finalizar la instalación se seleccionó Reiniciar ahora.

Posteriormente apareció el mensaje:

Please remove the installation medium, then press ENTER

Se retiró el medio de instalación virtual y se continuó con el reinicio.

15. Configuración inicial

Durante el primer inicio se revisaron las opciones de:

  • Cuentas en línea.
  • Livepatch.
  • Privacidad.
  • Servicios de ubicación.

16. Resultado final

Ubuntu 20.04.6 LTS inició correctamente y se accedió al escritorio.

Sistema operativo: Ubuntu 20.04.6 LTS
Arquitectura: 64 bits AMD64
RAM: 4096 MB
CPU: 2 procesadores
Disco virtual: 30 GB VDI
Red: NAT
Vídeo: 128 MB

17. Conclusión

La instalación de Ubuntu se completó correctamente dentro de Oracle VM VirtualBox. La máquina virtual quedó preparada para ser utilizada en prácticas de Seguridad Informática.
