Instalación de Ubuntu 20.04.6 LTS

Implementación de una máquina virtual Ubuntu 20.04.6 LTS utilizando Oracle VM VirtualBox, desde la creación de la máquina virtual hasta la puesta en funcionamiento del sistema operativo.

Sistema operativo Ubuntu 20.04.6 LTS
Arquitectura 64 bits (AMD64)
Hipervisor Oracle VM VirtualBox
Tipo de entorno Máquina virtual

1. Objetivo del laboratorio

Preparar un entorno virtual con Ubuntu 20.04.6 LTS para utilizarlo posteriormente en prácticas y laboratorios de Seguridad Informática, manteniendo el sistema operativo anfitrión aislado del entorno de pruebas.

2. Imagen ISO utilizada

Para la instalación se utilizó la imagen de escritorio de Ubuntu 20.04.6 LTS para equipos de 64 bits:

ubuntu-20.04.6-desktop-amd64.iso

La imagen ISO funciona como el medio de instalación que posteriormente se monta en la unidad óptica virtual de VirtualBox.

3. Creación de la máquina virtual

Desde Oracle VM VirtualBox se creó una nueva máquina virtual destinada exclusivamente a Ubuntu.

Configuración inicial
  • Nombre: Ubuntu 20.04.6
  • Tipo: Linux
  • Versión: Ubuntu (64-bit)

4. Asignación de memoria RAM

Se asignaron 4096 MB de memoria RAM a la máquina virtual. Esta cantidad proporciona recursos suficientes para ejecutar Ubuntu Desktop con mayor fluidez durante las prácticas.

Memoria RAM: 4096 MB (4 GB)

5. Configuración del procesador

En la configuración de Sistema → Procesador se asignaron dos procesadores virtuales.

Procesadores: 2 CPU

6. Creación del disco duro virtual

Se creó un disco virtual nuevo para almacenar Ubuntu y los archivos que se generen dentro de la máquina virtual.

  • Tipo de archivo: VDI (VirtualBox Disk Image)
  • Almacenamiento: reservado dinámicamente
  • Capacidad máxima: 30 GB

El almacenamiento dinámico permite que el archivo del disco virtual aumente de tamaño conforme se utiliza, hasta alcanzar el límite configurado.

7. Configuración de pantalla

Antes de iniciar la instalación se aumentó la memoria de vídeo disponible para la máquina virtual.

  • Memoria de vídeo: 128 MB
  • Controlador gráfico: VMSVGA

8. Montaje de la imagen ISO

Desde Configuración → Almacenamiento se seleccionó la unidad óptica virtual y se cargó la imagen ISO de Ubuntu.

ubuntu-20.04.6-desktop-amd64.iso

Una vez montada, la máquina virtual puede arrancar directamente desde el instalador de Ubuntu.

9. Inicio del instalador

Al iniciar la máquina virtual se mostró la pantalla de bienvenida de Ubuntu con dos alternativas:

  • Probar Ubuntu
  • Instalar Ubuntu

Para este laboratorio se seleccionó Instalar Ubuntu.

10. Idioma y distribución del teclado

Se seleccionó Español como idioma del instalador y posteriormente la distribución:

Spanish (Latin American)

Se verificó el funcionamiento de caracteres especiales, incluyendo el símbolo @, antes de continuar.

11. Actualizaciones y software

Durante el proceso de instalación se seleccionó la instalación normal de Ubuntu.

  • Instalación normal.
  • Descargar actualizaciones al instalar Ubuntu.
  • Instalar software de terceros.

12. Tipo de instalación

El instalador mostró la opción Borrar disco e instalar Ubuntu.

En este laboratorio esta opción afecta únicamente al disco duro virtual VDI de la máquina virtual. No corresponde al disco físico de Windows.

Después de confirmar los cambios, Ubuntu creó y formateó automáticamente las particiones necesarias.

13. Zona horaria

En la configuración de ubicación se seleccionó Lima, estableciendo la zona horaria correspondiente.

14. Creación del usuario

El instalador solicitó crear la cuenta que se utilizará para iniciar sesión en Ubuntu.

También se configuró el sistema para solicitar contraseña al iniciar sesión, una opción recomendable para mantener control de acceso sobre la máquina virtual.

Las contraseñas utilizadas durante los laboratorios no deben publicarse en GitHub ni incluirse en capturas públicas.

15. Instalación del sistema

Ubuntu comenzó a copiar archivos, instalar paquetes y configurar los componentes del sistema operativo.

Durante este proceso se mostraron diferentes pantallas informativas sobre las aplicaciones incluidas en Ubuntu, como LibreOffice.

16. Reinicio de la máquina virtual

Finalizada la instalación, se seleccionó Reiniciar ahora.

Durante el reinicio apareció el mensaje:

Please remove the installation medium, then press ENTER

Después de retirar el medio de instalación virtual y continuar con el arranque, Ubuntu inició desde el disco virtual recién instalado.

17. Configuración inicial de Ubuntu

En el primer inicio se completó el asistente de bienvenida. Se revisaron opciones como cuentas en línea, Livepatch, privacidad y servicios de ubicación.

Las cuentas en línea son opcionales y no son necesarias para realizar las prácticas del laboratorio.

18. Resultado final

La instalación terminó correctamente y Ubuntu 20.04.6 LTS inició en su entorno de escritorio.

✓ Máquina virtual operativa

Ubuntu 20.04.6 quedó instalado y preparado como entorno virtual para las siguientes prácticas de Seguridad Informática.

19. Configuración final de la máquina

  • Sistema operativo: Ubuntu 20.04.6 LTS
  • Arquitectura: AMD64 / 64 bits
  • Memoria RAM: 4096 MB
  • Procesadores: 2 CPU
  • Disco virtual: VDI de 30 GB
  • Almacenamiento: reservado dinámicamente
  • Memoria de vídeo: 128 MB
  • Controlador gráfico: VMSVGA
  • Red: NAT

Conclusión

Mediante esta práctica se implementó un sistema Ubuntu completamente virtualizado. El uso de VirtualBox permite disponer de un entorno independiente y controlado para realizar futuras pruebas y ejercicios sin modificar directamente el sistema operativo anfitrión.
