Kali Linux 2026.2 en Oracle VM VirtualBox

Manual de preparación y configuración de Kali Linux para prácticas de Seguridad Informática.

1. Objetivo

Preparar Kali Linux 2026.2 como máquina virtual dentro de Oracle VM VirtualBox, dejando el entorno listo para futuras prácticas académicas de Seguridad Informática.

2. Tipo de instalación utilizada

En este caso Kali Linux no se instaló desde una imagen ISO como Ubuntu. Se utilizó una máquina virtual ya preparada específicamente para VirtualBox.

Kali Linux Rolling 2026.2
Arquitectura: AMD64 / 64 bits
Tipo: máquina virtual preparada para VirtualBox

3. Archivos utilizados

Después de extraer la descarga de Kali se obtuvieron los archivos principales de la máquina virtual:

kali-linux-2026.2-virtualbox-amd64.vbox
kali-linux-2026.2-virtualbox-amd64.vdi

El archivo .vbox contiene la configuración de la máquina virtual, mientras que el archivo .vdi corresponde al disco duro virtual.

4. Incorporación de Kali a VirtualBox

Paso 1. Abrir la carpeta de Kali

Se accedió a la carpeta donde se encontraban los archivos extraídos de Kali Linux.

Paso 2. Abrir el archivo .vbox

Se ejecutó el archivo:

kali-linux-2026.2-virtualbox-amd64.vbox

VirtualBox reconoció automáticamente la máquina virtual y la agregó a la lista de máquinas disponibles.

5. Configuración detectada

Nombre: kali-linux-2026.2-virtualbox-amd64
Sistema detectado: Debian (64-bit)
Memoria RAM: 2048 MB
Procesadores: 2 CPU
Memoria de vídeo: 128 MB
Controlador gráfico: VMSVGA
Disco virtual: 80.09 GB
Red: NAT

Esta configuración fue reconocida automáticamente por VirtualBox al cargar la máquina preparada de Kali Linux.

6. Configuración de almacenamiento

VirtualBox reconoció el disco virtual asociado a Kali:

kali-linux-2026.2-virtualbox-amd64.vdi

El disco se encontraba conectado mediante un controlador SATA.

7. Configuración de red

La máquina virtual quedó configurada utilizando el modo de red:

NAT

Esta configuración permite que Kali utilice la conexión a Internet del equipo anfitrión sin exponer directamente la máquina virtual a la red física.

8. Primer inicio de Kali Linux

Paso 3. Iniciar la máquina virtual

Con Kali seleccionada en VirtualBox se presionó el botón Iniciar.

Kali Linux comenzó el proceso de arranque y posteriormente mostró la pantalla de inicio de sesión.

9. Inicio de sesión

La imagen preparada de Kali Linux incluía las siguientes credenciales iniciales:

Usuario: kali
Contraseña inicial: kali
La contraseña predeterminada debe cambiarse posteriormente si la máquina va a conservarse para uso continuo.

10. Acceso al escritorio

Después de iniciar sesión se accedió correctamente al escritorio gráfico de Kali Linux.

Con esto se verificó que la máquina virtual arrancaba correctamente dentro de Oracle VM VirtualBox.

11. Comprobación básica de red

Para validar la conectividad puede abrirse una terminal y ejecutar:

ping -c 4 8.8.8.8

Si se reciben respuestas, significa que la máquina tiene conectividad IP.

12. Actualización del sistema

Una vez comprobada la conectividad, se recomienda actualizar la información de los repositorios:

sudo apt update

Después puede actualizarse el sistema con:

sudo apt full-upgrade -y
No apagar la máquina virtual ni interrumpir el proceso mientras se estén instalando actualizaciones.

13. Uso previsto de Kali Linux

Kali Linux será utilizado principalmente como máquina de trabajo para prácticas de Seguridad Informática.

Entre sus posibles usos académicos se encuentran:

  • Análisis de redes.
  • Comprobación de conectividad.
  • Escaneo de servicios dentro de laboratorios autorizados.
  • Prácticas de seguridad sobre máquinas virtuales propias.
Las herramientas de Kali deben utilizarse únicamente en equipos, redes y servicios propios o expresamente autorizados.

14. Exportación como archivo OVA

Para transportar la máquina virtual a otro equipo se puede exportar Kali Linux como archivo OVA.

Paso 4. Apagar Kali Linux

Antes de exportar, la máquina virtual debe encontrarse completamente apagada.

Paso 5. Abrir la opción de exportación

En VirtualBox se selecciona:

Archivo → Exportar servicio virtualizado

Paso 6. Seleccionar Kali Linux

Se selecciona únicamente la máquina Kali Linux que se desea exportar.

Paso 7. Elegir el formato OVA

Se utiliza Open Virtualization Format y un nombre de archivo terminado en:

.ova

El archivo puede guardarse directamente en un disco duro externo para transportarlo al aula.

15. Recomendaciones para el respaldo

Junto con el archivo OVA se recomienda conservar:

  • El instalador de la versión de VirtualBox utilizada.
  • El manual de Kali Linux.
  • El archivo OVA de Ubuntu.
  • La documentación correspondiente al laboratorio.
