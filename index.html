Instalación de Ubuntu 20.04.6 LTS

Implementación de una máquina virtual Ubuntu 20.04.6 LTS utilizando Oracle VM VirtualBox, desde la creación de la máquina virtual hasta la puesta en funcionamiento del sistema operativo.

Sistema operativo Ubuntu 20.04.6 LTS
Arquitectura 64 bits (AMD64)
Hipervisor Oracle VM VirtualBox
Tipo de entorno Máquina virtual

1. Objetivo del laboratorio

Preparar un entorno virtual con Ubuntu 20.04.6 LTS para utilizarlo posteriormente en prácticas y laboratorios de Seguridad Informática, manteniendo el sistema operativo anfitrión aislado del entorno de pruebas.

2. Imagen ISO utilizada

Para la instalación se utilizó la imagen de escritorio de Ubuntu 20.04.6 LTS para equipos de arquitectura AMD64.

Archivo utilizado:
ubuntu-20.04.6-desktop-amd64.iso

3. Creación de la máquina virtual

Paso 1. Crear una nueva máquina virtual

Desde Oracle VM VirtualBox se seleccionó la opción Nueva para comenzar la creación de la máquina virtual.

Se configuraron los siguientes parámetros:

Nombre: Ubuntu 20.04.6
Tipo: Linux
Versión: Ubuntu (64-bit)

Paso 2. Asignación de memoria RAM

Se asignaron 4096 MB (4 GB) de memoria RAM a la máquina virtual.

Esta cantidad permite ejecutar Ubuntu de manera adecuada sin consumir excesivamente los recursos del equipo anfitrión.

Paso 3. Creación del disco duro virtual

Se seleccionó la opción Crear un disco duro virtual ahora.

Como formato de disco se utilizó:

VDI (VirtualBox Disk Image)

El almacenamiento fue configurado como reservado dinámicamente.

Se asignó un tamaño máximo de:

30 GB

Paso 4. Configuración del procesador

La máquina virtual fue configurada con 2 procesadores virtuales (CPU).

El límite de ejecución se mantuvo en 100 %.

4. Configuración de almacenamiento

Paso 5. Montaje de la imagen ISO

Desde la configuración de VirtualBox se ingresó a:

Configuración → Almacenamiento

En la unidad óptica del controlador IDE se seleccionó la imagen:

ubuntu-20.04.6-desktop-amd64.iso

Esto permite que la máquina virtual arranque desde el instalador de Ubuntu.

5. Inicio de la instalación de Ubuntu

Paso 6. Iniciar la máquina virtual

Se inició la máquina virtual desde Oracle VM VirtualBox.

Al cargar el instalador de Ubuntu se seleccionó el idioma Español.

Posteriormente se seleccionó:

Instalar Ubuntu

Paso 7. Configuración del teclado

Se seleccionó la distribución:

Spanish (Latin American)

Se verificó el funcionamiento de caracteres especiales como @ antes de continuar.

6. Actualizaciones y software

Paso 8. Tipo de instalación

Se seleccionó:

Instalación normal

También se habilitaron las opciones:

✓ Descargar actualizaciones al instalar Ubuntu.
✓ Instalar programas de terceros para hardware gráfico, Wi-Fi y formatos multimedia adicionales.

7. Configuración del disco

Paso 9. Instalación en el disco virtual

Se seleccionó:

Borrar disco e instalar Ubuntu

Esta operación afecta únicamente al disco virtual creado para la máquina virtual, no al disco físico donde se encuentra instalado Windows.

Posteriormente se confirmó la escritura de los cambios en el disco virtual.

8. Zona horaria

Paso 10. Selección de ubicación

Se seleccionó Lima como ubicación, estableciendo la zona horaria correspondiente.

9. Creación del usuario

Paso 11. Configuración de la cuenta

Durante la instalación se creó la cuenta de usuario del sistema.

Se configuraron:

• Nombre del usuario.
• Nombre del equipo.
• Nombre de inicio de sesión.
• Contraseña de acceso.

Se seleccionó la opción:

Solicitar mi contraseña para iniciar sesión.

10. Proceso de instalación

Paso 12. Instalación de los componentes

Ubuntu comenzó automáticamente la copia de archivos, instalación de paquetes y configuración del sistema operativo.

Durante este proceso se instalaron también aplicaciones incluidas con Ubuntu, entre ellas LibreOffice y diferentes utilidades del sistema.

11. Reinicio del sistema

Paso 13. Finalizar instalación

Una vez terminada la instalación se seleccionó:

Reiniciar ahora

Posteriormente apareció el mensaje:

Please remove the installation medium, then press ENTER

Se retiró la imagen ISO de la unidad virtual y se presionó ENTER para continuar.

12. Configuración inicial de Ubuntu

Paso 14. Primer inicio

Después del reinicio se inició sesión con el usuario creado durante la instalación.

Ubuntu mostró el asistente inicial de configuración.

Durante este proceso se revisaron opciones relacionadas con:

• Cuentas en línea.
• Ubuntu Livepatch.
• Privacidad.
• Servicios de ubicación.
• Aplicaciones disponibles.

13. Escritorio de Ubuntu

Paso 15. Verificación final

Una vez finalizada la configuración inicial se accedió correctamente al escritorio de Ubuntu 20.04.6 LTS.

Con esto se comprobó que la máquina virtual se encontraba correctamente instalada y operativa.

14. Configuración final de la máquina virtual

Memoria RAM 4096 MB
Procesadores 2 CPU
Disco virtual 30 GB VDI
Red NAT

Resultado del laboratorio

Se completó satisfactoriamente la instalación y configuración de Ubuntu 20.04.6 LTS dentro de Oracle VM VirtualBox.

El entorno virtual quedó disponible para realizar posteriormente prácticas de Seguridad Informática sin afectar directamente al sistema operativo anfitrión.
